# Full modern MCC port

The required scope is the complete current MinecraftClient runtime, including its
TUI/minimap, inventory, terrain, physics/pathfinding, commands, bots, runtime C#
scripting, authentication/signing and integrations. The historical Mono console
under ../ish remains a working prototype, not the final full port.

`CompatibilityProbe.csproj` is generated by tools/audit-ish-full-port.py. It probes
whether the modern dependency versions can target Mono's net472 API surface.
It deliberately has no application sources and is **not** a client implementation.
Restore failures identify runtime/dependency blockers; restoring successfully would
not prove runtime compatibility. The modern source inventory is progress/full-scope.json.

No feature may be considered complete merely because a placeholder compiles,
a gate disables it, a command reports unsupported, or its source is present.
Full completion requires the modern runtime/source and all main-client features to
build and execute on the target, with feature-specific behavior tested.

The separate [modern Mono native experiment](MODERN-MONO.md) probes whether the
current runtime can build on Alpine x86 while preserving JIT, reflection and
threading. It is a feasibility check, not a replacement client or runtime release.
